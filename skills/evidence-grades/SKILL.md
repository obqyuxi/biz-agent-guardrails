# 证据等级

对关键断言标注其一（中文标签可与英文并存）：

| 标签 | 含义 | 典型来源 |
|------|------|----------|
| **已核实** | 本轮用工具/源码/日志/正式数据核对过 | 查询结果、文件 diff、HTTP 200+正文 |
| **待确认** | 合理推断或过时记录，尚未复核 | 旧文档、口头习惯、未复跑的脚本 |
| **仅本地** | 只在本机/沙箱成立，不代表生产 | 本地 mock、未连生产的配置 |
| **生产** | 已对生产或准生产环境核实 | 生产只读查询、线上配置回读 |

## 硬规则

1. 没有证据就不要写成像已核实的句子；改为「待确认」并写缺什么。
2. 「页面打开了 / health 200」≠ 端到端验收通过。
3. 过期指标（带日期的报表）复用前必须复核。
4. 禁止把示例数据（`EXAMPLE`）说成真实业务结果。

## 回复示例

> 本月现金业绩为 EXAMPLE 128.6 万。【仅本地·示例】真实环境需用正式只读入口重查。【待确认】

## 验收

每条关键数字或「已完成」声明都能指向一个证据等级。
