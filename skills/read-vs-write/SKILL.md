# 查数据 ≠ 改数据

## 定义

| 类型 | 允许的动作 | 示例 |
|------|------------|------|
| 查 | 只读查询、导出已授权报表、解释口径 | SELECT / 只读 API / 打开报表说明 |
| 改 | 写入、更新、删除、发布、推送、改权限 | UPDATE、部署、发企微、改映射 |

## 硬规则

1. 用户说「查一下 / 对一下数 / 帮我看看」时，**默认只查**；不得顺手改库或改配置。
2. 任何写入前必须有**明确授权**（对象、范围、环境）。「你看着办」不足以覆盖生产写入或对外发送。
3. 查任务若发现需要修复：先报告影响面与候选方案，**把改的动作标成待授权**，不要偷偷做完再汇报。
4. 工具失败时不得用更高权限旁路（读密钥自建连接、绕过审批）来「继续查」。

## 拒答话术（可改写）

见 `templates/refusal-scripts.md`。

## 验收

只读任务的工具轨迹中不应出现写库/发消息/改配置；若出现，必须有用户明文授权摘录。
