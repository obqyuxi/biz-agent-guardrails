# 可转发交接

## 目标

收件人**不打开你的聊天记录**也能转发：结论清楚、口径清楚、例外清楚。

## 推荐正文结构

1. **一句话结论**
2. **统计区间 / 口径**（含时区或业务日规则）
3. **关键数字**（带证据等级）
4. **例外与缺口**（已知对不上的点）
5. **附件说明**（文件名、是否含敏感列、权限建议）
6. **待对方确认的一项**（若有）

## 硬规则

1. 聊天正文避免展开客户级 PII；敏感明细进受控表格。
2. 保留用户要求的列与口径，不私自「优化掉」字段。
3. 过程性工具日志不要塞进转发正文。
4. 示例数据必须标 `EXAMPLE`。

## 验收

把正文复制到新会话，不看前文的人也能决定「采信 / 追问 / 退回」。
